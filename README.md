# multilingual-sentence-thesis

## Project Overview

This repository is organized into three main folders:

- `parallel-sentence-matching`
- `parallel-sentence-mining`
- `centroid-anaylsis`

Each of these folders contains its own detailed README with the instructions needed to run that part of the project.

### `parallel-sentence-matching`

This folder contains the code for the **parallel sentence matching** experiments.  
The goal here is to evaluate how well multilingual embedding models can identify the correct parallel sentence when the candidate set is known.

### `parallel-sentence-mining`

This folder contains the code for the **parallel sentence mining** experiments.  
The goal here is to retrieve parallel sentence pairs from larger collections of sentences, which is a more open retrieval setting than sentence matching.

### `centroid-anaylsis`

This folder contains the code for the **centroid-based embedding space analysis**.  
It is used to analyze the structure of the multilingual embedding spaces, for example through centroid computation, distance calculations, and visualizations such as t-SNE.

## Note

Please open the README inside the corresponding folder for the full setup and run instructions.
